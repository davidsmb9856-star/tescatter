RUMUS ODDS MINUS (MINES)

💎 RUMUS BAYARBayar = |odds| × Target Menang
Contoh: 1.33 × 10.000 = 13.300
✅ JIKA MENANGDiterima = Bayar + Target
13.300 + 10.000 = 23.300
❌ JIKA KALAHHilang seluruh bayaran
Rugi = 13.300 (100%)
📊 DESIMALDesimal = 1 + (1 ÷ |odds|)
−1.33 → 1 + 0.7519 = 1.7519

CONTOH PERHITUNGAN LENGKAP

CONTOH: 2 TARUHAN MINUS

target menang: rp 10.000 / taruhan taruhan a: odds -1.33 bayar = 1.33 × 10.000 = rp 13.300 menang → terima = 13.300 + 10.000 = rp 23.300 taruhan b: odds -1.42 bayar = 1.42 × 10.000 = rp 14.200 menang → terima = 14.200 + 10.000 = rp 24.200 total harus dibayar = 13.300 + 14.200 = rp 27.500 jika keduanya menang: diterima = 23.300 + 24.200 = rp 47.500 profit = 47.500 - 27.500 = rp 20.000

SKENARIO KALAH

total dibayar: rp 27.500 skenario 1: hanya a menang diterima = rp 23.300 bersih = 23.300 - 27.500 = -rp 4.200 (rugi) skenario 2: hanya b menang diterima = rp 24.200 bersih = 24.200 - 27.500 = -rp 3.300 (rugi) skenario 3: semua kalah diterima = rp 0 rugi = -rp 27.500 (100%) ⚠️ odds minus = unggulan peluang menang > 50% tapi bayaran lebih besar dari target

ODDS PLUS (PEMBANDING)

odds plus: +1.85 modal: rp 10.000 rumus: untung = modal × odds = 10.000 × 1.85 = rp 18.500 total diterima = 10.000 + 18.500 = rp 28.500 perbandingan: minus -1.33: bayar 13.300 → untung 10.000 plus +1.85: bayar 10.000 → untung 18.500 odds plus = non-unggulan peluang menang < 50% tapi bayaran lebih besar dari modal

KONVERSI ODDS

konversi odds minus ke desimal: -1.33 → 1 + (1÷1.33) = 1.7519 -1.42 → 1 + (1÷1.42) = 1.7042 -1.50 → 1 + (1÷1.50) = 1.6667 -2.00 → 1 + (1÷2.00) = 1.5000 konversi odds plus ke desimal: +1.00 → 1 + 1.00 = 2.0000 +1.50 → 1 + 1.50 = 2.5000 +1.85 → 1 + 1.85 = 2.8500 +3.40 → 1 + 3.40 = 4.4000 peluang implisit = 1 ÷ desimal × 100% -1.33 → 1÷1.7519 = 57.08% +1.85 → 1÷2.8500 = 35.09%
