RUMUS ODDS MINUS (MINES)

💎 RUMUS BAYARBayar = |odds| × Target Menang
Contoh: 1.33 × 10.000 = 13.300
✅ JIKA MENANGDiterima = Bayar + Target
13.300 + 10.000 = 23.300
❌ JIKA KALAHHilang seluruh bayaran
Rugi = 13.300 (100%)
📊 PELUANGOdds minus = unggulan
Peluang menang > 50%

CONTOH LENGKAP

2 TARUHAN MINUS

target menang: rp 10.000 / taruhan taruhan a: odds -1.33 bayar = 1.33 × 10.000 = rp 13.300 menang → terima = 13.300 + 10.000 = rp 23.300 taruhan b: odds -1.42 bayar = 1.42 × 10.000 = rp 14.200 menang → terima = 14.200 + 10.000 = rp 24.200 total harus dibayar = 13.300 + 14.200 = rp 27.500 jika keduanya menang: diterima = 23.300 + 24.200 = rp 47.500 profit = 47.500 - 27.500 = rp 20.000

SKENARIO KALAH

total dibayar: rp 27.500 skenario 1: hanya a menang diterima = rp 23.300 bersih = 23.300 - 27.500 = -rp 4.200 skenario 2: hanya b menang diterima = rp 24.200 bersih = 24.200 - 27.500 = -rp 3.300 skenario 3: semua kalah rugi = -rp 27.500 (100%) ⚠️ odds minus = unggulan bayar lebih besar dari target

ODDS PLUS (PEMBANDING)

odds plus: +1.85 modal: rp 10.000 untung = 10.000 × 1.85 = rp 18.500 diterima = 10.000 + 18.500 = rp 28.500 perbandingan: minus -1.33: bayar 13.300 → untung 10.000 plus +1.85: bayar 10.000 → untung 18.500 odds plus = non-unggulan peluang menang < 50% bayaran lebih besar dari modal

TABEL REFERENSI

odds minus → bayar per target 10.000: -1.10 → bayar 11.000 → terima 21.000 -1.20 → bayar 12.000 → terima 22.000 -1.33 → bayar 13.300 → terima 23.300 -1.42 → bayar 14.200 → terima 24.200 -1.50 → bayar 15.000 → terima 25.000 -2.00 → bayar 20.000 → terima 30.000 odds plus → untung per modal 10.000: +1.00 → untung 10.000 → terima 20.000 +1.50 → untung 15.000 → terima 25.000 +1.85 → untung 18.500 → terima 28.500 +3.40 → untung 34.000 → terima 44.000
