Penjelasan Rumus Asian Handicap
✅ Menang Penuh Return = Modal × Odd
Profit = Return - Modal
Contoh: 100K × 1.90 = 190K (profit 90K)
⚡ Menang 1/2 (Half Win) Return = Modal × [((Odd-1)÷2) + 1]
Contoh: Odd 1.90 → eff = ((0.90÷2)+1) = 1.45
Return = 100K × 1.45 = 145K (profit 45K)
⚠️ Kalah 1/2 (Half Lose) Return = Modal × 0.50
Loss = Modal - Return
Contoh: 100K × 0.5 = 50K (rugi 50K)
🤝 Push / Seri (Void) Return = Modal × 1.00 (modal kembali)
Profit = 0
Terjadi saat selisih skor = handicap line bulat
❌ Kalah Penuh Return = Rp 0
Loss = -Modal (rugi 100%)
📊 Quarter Handicap 0.25: Seri = menang 1/2
0.75: Menang 1 gol = menang 1/2
1.25: Menang 1 gol = kalah 1/2
1.75: Menang 2 gol = menang 1/2
